# Floating Hand

`smplx_right_hand_floating.urdf` is the simulator-ready 51-DoF hand:

- 3 virtual prismatic wrist-position joints,
- 3 wrist rotation joints,
- 45 finger joints.

It is generated from `hands/smplx_variants/hands_only/smplx_right_hand.urdf` by `dataset/geometric/build_hand_urdf.py`.
